# Drag and Drop — Fast Food Matching Game

A drag-and-drop matching game built with vanilla JavaScript. Drag each food item to its matching image.

**Stack:** HTML, CSS, JavaScript
**Live:** https://dragndropnrqz.vercel.app/

## Features

- Drag-and-drop matching with visual feedback (correct/incorrect)
- Score counter (out of 10)
- Timer tracks how fast you complete the game
- Reset button to restart
- Celebration message on completion
- Mobile-friendly responsive layout

Demonstrates: HTML5 drag-and-drop API, DOM manipulation, event handling, vanilla JS interactivity.
